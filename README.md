# UCI Heart Disease ML Classification

Machine learning based heart disease classification using the UCI Heart Disease dataset.

## Models Used

- Decision Tree
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Support Vector Machine (SVM)

## Dataset

This project uses the UCI Heart Disease dataset obtained from Kaggle.

### Kaggle Dataset
https://www.kaggle.com/datasets/redwankarimsony/heart-disease-data

## Workflow

1. Dataset Loading
2. Data Inspection
3. Missing Value Handling
4. Target Conversion
5. Categorical Feature Encoding
6. Train-Test Split
7. Feature Scaling
8. Model Training
9. Model Prediction
10. Performance Evaluation
11. Confusion Matrix
12. ROC Curve
13. Model Comparison

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix
- ROC Curve

## Results

The four machine learning models were trained and evaluated using the same train-test split.
